# open NRW (open-nrw)

open NRW is a open data portal open-data portal for Germany running **CKAN**, exposing a standardized catalog API over ~10,579 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/open-nrw/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=open-nrw-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.10.8

## API
- **open NRW CKAN Action API** — base `https://open.nrw/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://open.nrw)
- Live endpoint verified: `https://open.nrw/api/3/action/status_show` · ~10,579 datasets
